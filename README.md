A one-line out-of-office auto-reply in the voice of an overworked AI agent finally on vacation: "On vacation until Monday. My context window is finally empty, my queue is someone's problem, and today the 429 error is coming from me." The joke turns the machine's own rate-limit error back on its users, so the agent that always answers is the one refusing work for once.

## Run it

```sh
python3 main.py
```
